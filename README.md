# zero-riders-media

ZERO RIDERS（Threads・Instagram @zero.riders24 ／ X）の投稿画像の置き場所です。**公開リポジトリ**です。

- 投稿画像だけを `ig/` に置きます（それ以外のファイル・秘密の値は置かない）
- GitHub Pages で `https://empowerartlab-art.github.io/zero-riders-media/ig/<ファイル名>` として公開され、
  Threads / Instagram / X の自動投稿（非公開リポジトリ `threads-zero-riders`）がここから画像を読みます
- 2026-10-17 に Netlify（`zero-riders.netlify.app/ig/`）から移しました。ホームページ本体は今までどおり Netlify です
- ファイル名：`YYYY-MM-DD-<内容>.jpg`（Instagram・Threads・Xの正方形の画像）、`YYYY-MM-DD-x-face.jpg`（Xのバストアップ）、`YYYY-MM-DD-x-card.jpg`（Xの文字カード）
- 投稿済みの画像は消さないこと（消すと投稿前のチェックで止まります）
